## 1. 怎么读

1. 先看第 2 节分层和第 3 节请求怎么穿层，再按目录查文件表。
2. 「进 APK」指随签名 Release 打进 `com.hongtai.aiagent`；CLI / Node I/O / 开发脚本不进 APK。
3. 文件职责以该文件的导出和注释为准，不以旧文档为准。

## 2. 一句话定位与分层

面向大健康门店老板的**本地优先 Android APK**。没有自有远程后端、没有登录、没有云同步。React 跑在 WebView 里，业务逻辑是共享 TypeScript，Kotlin 只做系统 I/O。

```text
用户手指
    ↓
apps/web（React 应用界面层）
    ↓ 只使用 AppRuntime 与版本化 DTO
packages/capacitor-runtime（组合层：装配 Flow 与原生端口）
    ↓
packages/core + packages/ai + packages/platforms
    ↓ Capacitor Bridge
android/app 九个自定义插件 + 官方 @capacitor/app
    ↓
Keystore / 应用私有目录 / Photo Picker / 外部相机 / HTTPS / Media3 / HEIF JNI
```

开发机另有一条平行适配，**不进 APK**：

```text
apps/cli → 同一套 core / ai / platforms → packages/node-runtime（FFmpeg、sharp、workspace 文件）
```

浏览器 `pnpm --filter @hongtai/web dev` 用 `apps/web/src/runtime/browser-native` 假装原生端口，便于页面回归。浏览器**不能** Media3 合成，`render` 会得到 `MEDIA_ENCODER_UNAVAILABLE`。

## 3. 一次操作怎么穿层

### 3.1 粘贴公开链接采集

`TaskHomePage` 调 `tasks.inspectInput`（`packages/core` 的纯函数，不发网）。用户确认后 `tasks.create` + `start`。`StandaloneTaskService` 跑唯一的 `IngestPipeline` 七阶段：平台识别 → 短链解析 → `packages/platforms` 取公开页 → 选媒体 → `NativeNetwork` 下载到私有目录 → ASR/文稿 → 原子保存 `task.json` 与 `events.jsonl`。页面只订阅阶段事件，不读 Cookie、原始 HTML 或私有路径。

### 3.2 内容拆解

公网任务需用户确认后 `analysis.run`；本地 MP4 走 `analysis.importVideo`，采集成功后自动拆解。`ContentAnalysisFlow` 一次结构化流式调用，顶层五字段闭合且通过 Zod 后才发 `structured-generation-progress.v1`。完整文档再校验为 `content-analysis.v1` 并原子写入 `analysis.json`。深度思考只在内存。

### 3.3 舌象 / 面部观察

`diagnosis.pickImage` / `captureImage` 把一张图拷进 `observations/<sessionId>/`。`DiagnosisFlow` 同样一次流式调用，八个顶层字段组装成五个展示板块，正式结果是 `diagnosis-report.v1`。追问是自由文本例外：`content_delta` 可逐段上屏，持久化仍要校验后的消息。

### 3.4 Agent 制作成片

制作首页两张入口卡。Agent：`production.create`（需已成功拆解）→ 用户导入素材 → 规划前可对每条素材 `insightFrames` + `AssetInsightFlow`（失败记 `blind`，不拦成片）→ `ProductionPlanningFlow` 产出 **v2 JSON + 贴纸选择** → `withSubtitleTimeline` 在 TypeScript **组装并校验 v3** → 用户点合成 → `ProductionRuntimePlugin` 用 Media3 烧录 720×1280 H.264/AAC。

### 3.5 爆款复刻

`replica.run` 把 `content-analysis.v1` 变成 `replica-blueprint.v1` 清单（无 `assetId`），落在 `tasks/<taskId>/replica-blueprint.json`。`startProject` 用清单秒数合计建项目。逐项 `importAssets(..., { requirementOrder })` 在打开系统选择器**之前**把归属写入 `project.json`。`generatePlan` 硬校验镜头顺序等于已绑定项的相对顺序。向导结束后进 `/create/:projectId/edit` 微调，成片仍回制作页 `render`。

### 3.6 导出微调

`production.updatePlan` 带 `expectedUpdatedAt` 乐观校验。字幕时间轴一律按文案重建，不接受调用方传入的 cue 毫秒。保存成功会作废旧成片。数字人模式锁口播与时长。

## 17. 刻意没有的依赖

- 无 React Router / Redux / Zustand / Tailwind / CSS-in-JS / antd / Radix。
- 产品图标不另维护一套 path：统一 Lucide 字形 + `Icon.tsx`。
- `core` / `platforms` 零生产 npm 依赖；`ai` 只有 `zod`。
- Kotlin 不用协程库做业务编排（命名 Executor）；Keystore AES-GCM 自写，无 `security-crypto`。
- 无 SQLite / SQLCipher。
- 无账号、云同步、发布 SDK。

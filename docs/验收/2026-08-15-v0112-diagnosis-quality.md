> 日期：2026-08-15

## 一、交付范围

- 诊察 Prompt 按“基础约束 → 思考方式 → 舌象或面部观察重点 → 完整 Markdown 知识库 → 末尾短提醒”组织。
- 清晰图片要求 3–6 条独立可见观察；轻微瑕疵归为有限可用并继续分析；只有目标缺失、严重遮挡、严重失焦或极端曝光等情况才允许不可用。
- 内部紧凑响应升级为 `diagnosis_single_response_v2`，最终公开报告仍为 `diagnosis-report.v1`，旧报告无需迁移。
- 传统观察方向允许 0–3 条，必须使用不确定措辞；没有组合依据时不强迫生成。
- 深度思考仍使用供应商真实流，不增加总结模型或过滤流水线；Prompt 明确要求聚焦图片证据、组合条件和干扰因素，并禁止讨论 Prompt、Schema 与 JSON 拼装。
- 后续追问只复用诊察安全边界，不再继承“只输出 JSON”的报告规则。
- 格式修复最多一次，只接收第一次文本结果，不重新发送图片或注入整份知识库。

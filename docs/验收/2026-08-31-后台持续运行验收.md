## 一、交付范围

| 层 | 交付物 | 说明 |
| --- | --- | --- |
| Android 原生 | `TaskGuardPlugin.kt`、`TaskGuardWakeLock.kt`、`BackgroundRunPolicy.kt`、`ic_stat_task_guard.xml` | WakeLock 按 kind 引用计数（模仿 `ActiveWorkScreenStayCounter`）；电池优化三级兜底引导（REQUEST → 列表页 → 应用详情）；后台运行策略位供亮屏保持分流 |
| Android 清单 | specialUse 前台服务声明 + `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_SPECIAL_USE`、`POST_NOTIFICATIONS`、`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 权限 | 服务指向 capawesome 插件 `AndroidForegroundService`，`PROPERTY_SPECIAL_USE_FGS_SUBTYPE` 如实描述本地 AI 内容制作任务的持续执行 |
| 第三方依赖 | `@capawesome-team/capacitor-android-foreground-service@8.1.0`（MIT，锁定精确版本） | 唯一新依赖；FGS 生命周期、通知渠道、`POST_NOTIFICATIONS` 权限 API；specialUse 经清单声明生效（不传 serviceType 走双参 `startForeground`） |
| 运行时 | `task-guard-client.ts`、`RuntimeOperationRegistry` 接线、`BackgroundRunService` core 契约、`standalone-app-runtime` 组装 | 四类长任务（ingest / content-analysis / diagnosis-report / production-plan / production-render）经 `operations.track` 自动护持；`transient-operation` 不护持；护持失败只降级存活率、绝不让任务本身失败 |
| Web UI | `background-run-preferences.ts`、SettingsPage「运行」区、`main.tsx` 偏好接线、ApplicationInfoPage 本版要点 | 主开关默认开启（localStorage 持久化）；电池优化/通知权限状态行只显示实测值；features=available 才显示整区（浏览器不画成已接通） |

## 四、未完成与真机待验清单

按[当前能力与发布状态](../当前能力与发布状态.md)的边界纪律，以下**不得声称已通过**：

1. **物理真机续跑**：一键制作运行中熄屏 5 分钟 → 返回任务仍在推进/完成；切后台同验。模拟器与浏览器无熄屏/Doze 真实环境。
2. **电池优化三级引导**：系统确认框一步豁免、拒绝后兜底列表页、再兜底应用详情页，返回后状态行如实刷新。
3. **FGS 通知行为**：状态栏「后台运行中」常驻通知显示；点击通知回到应用；任务终态后通知消失；Android 13+ 拒绝通知权限时服务仍运行且任务管理器可见。
4. **开关关闭回退**：关闭后台运行后，任务期间回到「保持屏幕常亮」的原行为（`FLAG_KEEP_SCREEN_ON`）。
5. **Deep Doze / 国产 ROM 边界**：熄屏静置 30 分钟以上与 MIUI/ColorOS 等自建休眠下的实际表现，设置页文案已如实声明「绝大多数场景」。
6. **公网分发**：APK 上传 `https://husteread.com/storage/public/HongTai-AI-Agent-release-v0.1.28.apk`、回验大小与 SHA-256、`download.html` 公开推荐切换——待用户确认后执行。

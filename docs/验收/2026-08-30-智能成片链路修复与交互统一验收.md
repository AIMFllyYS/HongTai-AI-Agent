## 修复清单

1. **一键制作必报「制作项目不存在或已损坏」（P0，100% 必现）**：composer 不选参考拆解时 `analysisTaskId` 为空串，`parseProject` 读取校验把空串判为损坏记录，管线第一步即抛错。三层同源修复——读取闸门接受空串（[standalone-production-record.ts](file:///d:/projects/Dev-Tools/HongTai-AI-Agent/packages/capacitor-runtime/src/standalone-production-record.ts)）、v4 计划 source 与校验约束按既有设计落 `null`（[standalone-production-service.ts](file:///d:/projects/Dev-Tools/HongTai-AI-Agent/packages/capacitor-runtime/src/standalone-production-service.ts) L772/L787，Kotlin 渲染器本已容忍 null）。
2. **新旧项目状态混杂（P0）**：工作台在 composer 期间不再自动选中旧项目；失败兜底不拉别的项目顶包、不刷新错对象；新增「上下文代际」识别迟到落地的一步操作成败（不再把旧项目错误写到新页面、也不把用户拽回去）。
3. **数字人无上传入口（P0）**：composer 打开「数字人出镜」即出现上传卡片，先传一段 MP4（草稿项目承载素材，走同一权威导入口径），未上传时「一键制作成片」禁用；一键复用草稿不二次创建项目。
4. **删除确认统一底部弹层（P1）**：新建共享组件 `ConfirmDeleteSheet`；制作面板（项目/素材/成片）、任务详情、模板页三处内嵌确认全部转为底部上拉弹层；死 CSS 清除；危险操作确认按钮改警示红色并明示「不可恢复」。
5. **排版与文案（P1）**：预估总时长 flex 断裂改行内自然流；悬浮主按钮增加内容底部让位（滚到底最后一行完整露出）；占位文案「例如：」化；生成中按钮如实显示「正在生成分镜脚本…」；工作台同一错误只保留内联横幅单面展示（不再顶部 toast + 横幅刷屏）；模板页双空态去重。
6. **通知生命周期（端测新发现）**：`IssueNotice` 的顶部通知与页面 issue 同生共死，页面清除 issue 时通知同步消失，不再赖在下一屏。

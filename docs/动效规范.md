# 动效规范

> 活文档。最后校对：2026-08-21。页面层动效只以本文 + 未归档 `hongtai-mobile.pen` 的组件形态为准。
> 2026-08-05 的 [mobile-interaction-motion-design](superpowers/specs/2026-08-05-mobile-interaction-motion-design.md) 是当时快照，冲突时以本文和源码为准。

应用界面层（`apps/web`）共用 `motion@12.43.0` 与 CSS token，不新增动画库。只动画 `transform`、`opacity`、颜色。`prefers-reduced-motion: reduce` 时关闭位移、回弹、骨架闪烁和拖拽弹性。

## 1. Token

| Token | 值 | 用途 |
| --- | ---: | --- |
| `--motion-duration-instant` | 80ms | 即时确认 |
| `--motion-duration-fast` | 140ms | 按压、遮罩 |
| `--motion-duration-standard` | 220ms | 弹层、底栏点击切页 |
| `--motion-duration-page` | 260ms | 二级路由进出 |
| `--motion-duration-skeleton` | 400ms | 路由/列表骨架最短可见时间 |
| `--motion-ease-standard` | `cubic-bezier(.2, 0, 0, 1)` | 常规 |
| `--motion-ease-emphasized` | `cubic-bezier(.2, .8, .2, 1)` | 进入、抬升、切页 |
| `--motion-distance-page` | 24px | 二级微滑入 |
| `--motion-distance-primary` | 约 28% 屏宽，上限 140px | 底栏点击切页 |
| `--overlay-scrim` | `rgba(27, 29, 31, 0.4)` | 所有弹层遮罩 |

JS 侧与 CSS 使用同一组语义，见 `apps/web/src/motion/tokens.ts`。

## 2. 三种页面切换，不许再发明第四种

| 种类 | 触发 | 观感 | 实现 |
| --- | --- | --- | --- |
| `primary-swipe` | 观察 / 拆解 / 模板 / 设置之间左右拖 | 整页跟手，松手吸附 | `SwipeRouteViewport`；提交后 `instant`，避免叠两次 |
| `primary` | 点击底栏四项 | 旧页滑出、目标页从对应侧滑入，**重叠、不等待退场** | `navigate(..., { transition: "primary", scroll: "auto" })` |
| `push` | 进二级：任务、设置子页、报告、微调、复刻、playbook、加号进 `/create` | 微微水平滑入 + 淡入；返回反向 | 默认 `navigate()`；`popstate` 同此 |

制作不在滑动位。加号进 `/create` 走 `push`。跨两个 Tab 的点击只播一次，不经过中间页。

`RouteTransition` 禁止 `mode="wait"`（会先等旧页退完再转圈）。使用 `popLayout` 让退场页脱离文档流，与入场重叠。底栏继续 portal 在路由 transform 之外。

冷启动第一帧不播切页动画。

## 3. Overlay 与 Sheet

所有「背后变暗 + 面板出现」只走 `Overlay`：

- `placement="rise"`：从下方上滑。加号新建、设置选项、任务更多、观察确认、观察追问。
- `placement="center"`：居中淡入。仅富迪素材库。

加号不是另一种菜单，它就是 `rise` Sheet。遮罩、Esc、点遮罩关闭、滚动锁定、`data-no-swipe` 都在 Overlay 里，页面不得再手写一套 backdrop。

Sheet 在 rise Overlay 之上：顶部必须有可拖的横杠（约 48×5px），表示可以拉把手或整张面板关闭。只许向下拖；位移超过 80px 或向下速度超过 450px/s 则关闭，否则回位。点行动行即选择。内容区滚动，从把手/标题区发起拖关闭。

## 4. 骨架屏

产品路径禁止全屏转圈 `LoadingState` 和「正在打开页面」整页。真实读取未完成时用 `PageSkeleton` 占位：灰块模仿该页结构，**禁止**填标题、数字、封面、进度百分比。

路由 `lazy()` 的 `Suspense` fallback 必须是目标路径的骨架，并包在 `RouteTransition` 里，让骨架跟着切页滑入。为避免缓存命中时骨架一闪而过，懒加载与列表读取使用 `skeletonHoldMs()`（默认 400ms；`prefers-reduced-motion` 时 80ms）。这不是假进度，不填数字或封面。

列表区局部读取（最近拆解、最近观察、模板列表）只骨架那一块。

页内分段 Tab（观察面部/舌象、拆解来源、结果两栏等）与路由共用同一套时长和缓动：指示条滑动，内容微微水平滑入。不另造第四种切页。

冷启动 `BrandSplash` 与 AI 五板块流光骨架不是本条：前者是开屏，后者是结构化生成进度。

## 5. 禁止

- 为单次使用再包一层动画框架或 re-export。
- 把 transform 打在底栏祖先上。
- 用等待退场 + 全屏转圈冒充加载。
- 骨架或过渡里编造业务数据。

# 错误码与应用界面通知约定

> 本文中的“界面”指应用界面层（Presentation / UI），不是传统 Web 前端；问题来源于本地应用逻辑层与平台运行时。
>
> 本文是[架构与工程规范](架构与工程规范.md)的配套稳定契约。页面只能读取代码和动作，不能通过中文文案、HTTP 文本或原生异常文本判断业务状态。

## 1. 统一问题契约

任务、设置、存储、媒体导入和 AI Flow 都通过同一个可展示的问题结构向 UI 暴露。对 URL 采集任务，`stage` 必须是七个 `TaskStage` 之一；对档案、加密存储或设置等非任务问题，`stage` 可以省略。

```ts
interface TaskIssue {
  code: ErrorCode;
  severity: "warning" | "error";
  stage?: TaskStage;
  userMessage: string;
  retryable: boolean;
  action: IssueAction;
  platform?: SupportedPlatform;
  details?: Record<string, string | number | boolean>;
}
```

`code`、`severity`、`retryable` 和 `action` 是稳定业务字段；`userMessage` 仅为默认中文兜底。`details` 只能包含脱敏的诊断信息，禁止放入 API Key、Authorization、Cookie、Token、签名 URL、完整查询参数、原始供应商错误正文或 base64 媒体。

`interrupted` 是首版可见的非成功终态，不能仅依靠一条错误弹窗替代状态记录。若任务中断需要引导用户重新开始，可同时附加 `TASK_INTERRUPTED` 问题；应用不自动恢复或自动重试任务。

## 2. 稳定错误码分类

| 分类 | 错误码 |
| --- | --- |
| 输入 | `INPUT_EMPTY`、`INPUT_TOO_LONG`、`INPUT_NO_SUPPORTED_URL`、`INPUT_URL_INVALID`、`INPUT_PLATFORM_UNSUPPORTED` |
| 链接 | `LINK_NETWORK_FAILED`、`LINK_TIMEOUT`、`LINK_REDIRECT_LIMIT`、`LINK_REDIRECT_INVALID`、`LINK_HTTP_ERROR`、`LINK_EXPIRED` |
| 内容 | `CONTENT_NOT_FOUND`、`CONTENT_REMOVED`、`CONTENT_PRIVATE_OR_LOGIN_REQUIRED`、`CONTENT_PARSE_FAILED`、`CONTENT_SCHEMA_CHANGED`、`CONTENT_TYPE_UNSUPPORTED` |
| 平台 API | `PLATFORM_API_RATE_LIMITED`、`PLATFORM_API_UNAVAILABLE`、`PLATFORM_API_RESPONSE_INVALID`、`PLATFORM_RISK_CONTROLLED` |
| 媒体与导入 | `MEDIA_SOURCE_NOT_FOUND`、`MEDIA_DOWNLOAD_FAILED`、`MEDIA_DOWNLOAD_TIMEOUT`、`MEDIA_DURATION_EXCEEDED`、`MEDIA_PROBE_FAILED`、`MEDIA_MERGE_FAILED`、`MEDIA_IMPORT_FAILED`、`MEDIA_READ_FAILED`、`MEDIA_SELECTION_CANCELLED` |
| AI 连接与调用 | `AI_NOT_CONFIGURED`、`AI_SETTINGS_INVALID`、`AI_SECRET_STORE_FAILED`、`AI_CAPABILITY_PROBE_FAILED`、`AI_AUTH_INVALID`、`AI_PERMISSION_DENIED`、`AI_QUOTA_EXHAUSTED`、`AI_RATE_LIMITED`、`AI_NETWORK_FAILED`、`AI_TIMEOUT`、`AI_SERVER_ERROR`、`AI_EMPTY_RESPONSE`、`AI_STRUCTURED_OUTPUT_INVALID`、`AI_FORMAT_REPAIR_FAILED`、`AI_VISION_UNAVAILABLE`、`AI_CONTEXT_SUMMARY_FAILED`、`AI_SESSION_NOT_FOUND`、`ASR_PARTIAL_FAILURE`、`TEXT_REWRITE_FAILED` |
| 图片观察 | `IMAGE_INVALID`、`IMAGE_TOO_LARGE`、`IMAGE_QUALITY_INSUFFICIENT`、`DIAGNOSIS_REPORT_INVALID`、`DIAGNOSIS_FOLLOW_UP_FAILED` |
| 本地档案与任务 | `PROFILE_SAVE_FAILED`、`TASK_ARTIFACT_MISSING`、`TASK_INTERRUPTED` |
| 本地存储 | `STORAGE_WRITE_FAILED`、`STORAGE_SPACE_INSUFFICIENT`、`STORAGE_PERMISSION_DENIED` |
| 内部 | `APP_RUNTIME_UNAVAILABLE`、`INTERNAL_UNKNOWN_ERROR` |

新增代码必须在实现前写入本表，说明其 `retryable` 语义和展示 `action`；不得将供应商或 Android 原始错误码直接暴露为业务代码。

`MEDIA_SELECTION_CANCELLED` 表示用户从系统相册或外部相机主动返回而未提交图片；它不可自动重试，默认 `action=select_media`，页面必须结束导入忙碌态并允许用户重新选择。

## 3. 建议动作与唯一展示层

| action | 应用界面层行为 |
| --- | --- |
| `edit_input` | 聚焦分享文案输入区，保留用户尚未提交的输入 |
| `retry` | 仅重新发起当前安全操作；URL 任务需由用户明确新建，旧任务不覆盖 |
| `wait_and_retry` | 提示稍后操作，避免连续请求 |
| `check_network` | 提示检查网络，并保留当前任务/会话 |
| `configure_ai` | 导航到 AI 设置页；不在弹窗中索取或回显完整 Key |
| `free_storage` | 引导用户释放空间或重新授权；不自动清理数据 |
| `select_media` | 打开系统媒体/文件选择流程，重新导入到应用私有目录 |
| `view_partial_result` | 打开已经安全保存的任务详情、媒体、图片或文稿 |
| `none` | 只显示信息，不提供专用按钮 |

应用只保留一个问题展示层（例如 `IssuePresenter`）负责把 `TaskIssue.code/action` 映射为弹窗、内联提示、重试、配置 AI、释放空间或查看部分结果。页面、Kotlin 插件和平台适配器都不得各自维护同一套中文分支。

## 4. 状态、通知与空态

- `severity=error`：当前操作不可继续；展示阻断弹窗或明确错误页，但保留已落盘的部分结果。
- `severity=warning`：任务可继续或已有部分产物；展示非阻断提示和可用结果。
- `queued`、`running`、`succeeded`、`degraded`、`failed`、`interrupted` 是首版任务状态，不通过 `severity` 推导。
- 内容拆解只使用独立 `analysisStatus`（`not_started`、`running`、`succeeded`、`failed`），不得伪装为 URL 采集第八阶段。
- 多链接被忽略只是输入检查信息，不生成 warning；实验性平台提示也是入口能力说明，不改变任务状态。
- 未实际获得的互动量、字幕、文稿、分析结论或媒体必须显示空态，不能以模拟数据降级为“成功”。

### 无口播不是错误

`speechStatus=no_speech` 表示 ASR 成功完成但没有检测到有效口播。它不生成 `TaskIssue`，不使任务降级，UI 应显示普通结果说明。存在失败分段且没有文字时为 `speechStatus=failed`，不得误判为无口播，也不得用平台描述冒充语音转写。

### 中断不是可自动恢复

首版不承诺后台续跑。若进程结束或启动检查发现未终态任务，原任务写为 `interrupted` 并保留已有产物。应用不自动重跑、不自动新建任务、不删除旧产物；用户从任务入口明确发起一次新的任务。

## 5. 重试、存储与安全

- 网络错误、HTTP 429 和 5xx 最多尝试 3 次，间隔为 0 秒、1 秒、3 秒；其中平台风控、内容删除、私密内容、输入错误和结构变化不自动重试。
- 429 明确表示 AI 余额或额度不足时使用 `AI_QUOTA_EXHAUSTED`，不自动重试；验证码或平台风控使用 `PLATFORM_RISK_CONTROLLED`，不自动重试。
- 私有文件写入失败不能触发“清空并重建”。保留已有产物、停止本次写入并提示用户处理。
- 导入失败不能把临时 `content://` URI 当作已保存素材；成功导入后才向 UI 返回应用私有目录的安全展示 URI。
- 日志只保留脱敏状态、阶段、平台、稳定代码和必要计数。供应商独立 reasoning 仅可进入私有调试材料，不属于正式结果，也不得进入后续对话上下文或 UI。

## 6. AI 与观察功能的边界

- 文本、视觉、ASR 的真实调用彼此独立；一个成功不表示其余能力可用。首版只在用户实际使用或明确点击测试时验证。
- `AI_NOT_CONFIGURED` / `AI_SETTINGS_INVALID` / `AI_SECRET_STORE_FAILED` 的默认动作是 `configure_ai`。
- 图片不符合质量条件时使用 `IMAGE_QUALITY_INSUFFICIENT`，页面引导重新选择或拍摄，而非生成医学结论。
- 图片观察报告及追问仅提供日常健康参考；不得通过错误或成功文案声称医疗诊断、疾病概率、处方或综合健康评分。

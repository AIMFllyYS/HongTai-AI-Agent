# 2026-09-01 存储管理 v2 重构（清理缓存 → 存储管理）

## 目标
- 用户可感知的结果：
  1. 设置页「清理缓存」升级为「存储管理」页：顶部设备存储总览卡（本应用占用与设备容量占比进度条），「占用分布」按拆解任务、舌诊面诊、制作项目、模板数据、缓存与临时文件、应用配置六区图例展示真实扫描结果。
  2. 缓存区点出底部操作 Sheet 一键清理；应用配置区点出说明 + 分组构成 + 导出报告 Sheet（系统分享）。
  3. 拆解任务、舌诊面诊、制作项目、模板数据四区进入 `/settings/storage/:area` 二级页逐项查看；舌诊面诊按舌诊/面诊分组；删除统一走 `ConfirmDeleteSheet` 二次确认，只展示脱敏相对路径（应用私有目录/<相对段>），绝对路径不跨桥。
  4. 数据文件始终标记为不可删除；旧「可定向清理 / 数据文件无法删除」两分区下线。

## 允许修改
- `packages/core/src/application-runtime.ts`（`storage-analysis.v2` 契约、`StorageService` 接口）及定向测试
- `packages/capacitor-runtime`（`native-storage.v2` 桥接与快照归一化）及定向测试
- `android/app/src/main/java/com/hongtai/aiagent/bridge/`（`LocalStoragePlugin.kt` 重写、新增可单测的 `StorageScanner.kt`）与 `StorageScannerTest.kt`
- `apps/web/src/pages/StorageAnalysisPage.tsx`、新增 `StorageAreaPage.tsx`、路由与相关 CSS
- 活文档：`docs/架构与工程规范.md`、`docs/交互信息架构规范.md`、`docs/当前能力与发布状态.md`、本任务契约

## 明确不做
- 不改 core/ai 的 Schema 与 Flow 契约以外的部分；不新增云端后端、登录、同步或系统权限
- 观察会话整体删除仍走观察模块既有入口，不在存储管理里重做
- 应用配置区不提供文件级明细与删除；`app_webview` 计入缓存大小但不提供文件级删除
- 不在 UI 展示绝对路径、原生 URI；不改 Keystore 行为
- 不做真机验收（本阶段只到主机构建与单测）

## 架构归属
- core：`storage-analysis.v2` 是 UI 可见快照的唯一契约——总快照只含六区聚合 + `device`（StatFs 设备总容量/剩余）+ `appDataGroups`，不逐文件返回
- Android I/O：`StorageScanner` 承担分类/聚合（修复业务目录恒 0B 与 busy 保护失效：原 classify 用 dataDir 相对路径首段，业务根都在 files/ 下永不命中）；`LocalStoragePlugin` 只做受控扫描、`listAreaItems`/`clearCache`/`exportReport`（FileProvider + 系统分享），不决定业务流程与文案
- UI（apps/web）：两个页面只消费 `AppRuntime.storage` DTO，按稳定 `TaskIssue.code` 分支
- 依赖方向不变：core 不导入运行时/平台 API；UI 不读取私有路径

## 权威状态与数据
- 状态权威来源：core `storage-analysis.v2` 契约（`application-runtime.ts`）、Android `StorageScanner.kt`（分类聚合规则）、`StorageAnalysisPage` 与 `StorageAreaPage`（页面结构）
- 删除句柄 opaque id 只在当前清单快照内有效；清单陈旧（`STORAGE_READ_FAILED` + retry）自动重新加载，删除失败保留原文件与既有成功状态
- 扫描快照带 `generatedAt`；清理/删除后重新读取真实快照，不伪造释放量

## 验收
- 定向测试：Android `:app:testReleaseUnitTest` 172 项全部通过，含新增 `StorageScannerTest` 10 项（分类、聚合、busy 保护、app_webview 边界）
- 构建 / lint：`pnpm check` 全绿；`pnpm --filter @hongtai/web build` 成功
- 浏览器或真机证据：桌面与约 390px 截图在 `output/storage-v2-ui/`（首页总览、缓存 Sheet、应用配置 Sheet、二级页、删除确认、清理完成 toast、非法分区兜底）
- 用户实际会看到什么：设置「数据」区「存储管理」进入真实扫描页；缓存可一键清理并提示真实释放量；四区二级页逐项删除需二次确认且只见脱敏相对路径；应用配置可导出系统分享报告

## 交付说明
- 改了什么：快照契约 v1→v2（聚合化 + 设备容量 + 配置分组）；`LocalStoragePlugin` 重写并抽出 `StorageScanner`；UI 重构为「存储管理」一页 + 四区二级页 + 两类 Sheet；活文档三处同步
- 刻意没有做什么：应用配置文件级删除、WebView 缓存文件级删除、观察会话整体删除入口迁移
- 未验证项 / 剩余风险：真机未验（StatFs 数值、FileProvider 分享、实际删除仅经单测与模拟）；浏览器开发态未真实删除文件（standalone IO 为开发替身，不声称 APK 行为）

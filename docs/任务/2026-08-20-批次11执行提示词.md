## 授权与禁止

- 读取仓库任何文件；修改当前 Loop 的 Issue 影响范围内文件及显然连带文件。
- 新增或修改测试；运行定向测试、`pnpm check`、`pnpm --filter @hongtai/web build`、相关 Gradle。
- 创建或启动本机 AVD、安装已签名 Release APK、用本机视频素材做端测。
- 每条 Loop 通过后本地 commit。不 push、不开 PR，除非用户另说。
- 禁止 `git add .`、worktree、Debug APK、假进度、泄露密钥、放宽断言。
- 小米 MiMo Key 只进入模拟器应用的 Android Keystore；不写入代码、日志、测试、文档、Issue、截图或 commit。
- 工作区未跟踪的 `docs/Hong/新设计/` 原样保留。

## Loop（每条 Issue 一轮）

```text
分析子代理（只读）
  → 主代理最小修复
  → 主代理亲自跑验证命令
  → 新的端侧验收子代理 与 新的代码审查子代理（并行）
  → 不通过则主代理返修（最多两次）
  → 无应修项则 commit，进入下一条
```

分析判定「已不成立」则跳过，不硬改。同一条端侧或审查返修两次仍不过：记录卡点，跳到下一条。只能靠真机/真网判定时记残留，不写「真机已过」。

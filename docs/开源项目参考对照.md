# 开源项目参考对照

## 1. 使用说明

本文档记录截至 2026-08-04 对“视频链接解析、视频下载、平台字幕和语音转写”相关项目的源码级调研结果。手机端视频编辑、Media3 与真人口播自动精剪的 2026-08-11 调研见[手机端基础视频编辑器与口播自动剪辑调研](手机端基础视频编辑器与口播自动剪辑调研.md)。

这些项目是设计和实现参考，不等于已经决定作为依赖。正式迁入代码前必须再次确认：

- 当前分支和真实运行结果；
- 开源许可证及商业使用条件；
- 是否依赖作者云端服务、第三方解析服务或账号 Cookie；
- 是否能迁移到 TypeScript/Capacitor/Android；
- 平台规则是否已变化。

## 2. 总体结论

目前没有发现一个可以直接放进 Capacitor Android APK，并同时稳定完成以下全部能力的成熟项目：

```text
抖音 + 小红书 + B站
链接解析 + 本地视频下载 + 平台字幕/本地ASR + 统一文稿输出
```

项目应采用自有最小核心和平台适配器结构，从不同项目中迁移经过验证且许可证允许的局部实现。

## 4. 用户指定项目

### 4.1 `Gazerrr03/cttk-crawl`

地址：[Gazerrr03/cttk-crawl](https://github.com/Gazerrr03/cttk-crawl)

仓库当前为私有仓库，未发现明确许可证。主要定位是：

```text
内容链接 -> 页面/元数据/图片抓取 -> Markdown本地归档
```

可参考：

- 平台链接识别；
- 短链接解析；
- B站元数据和平台字幕；
- Markdown内容归档；
- 平台策略和降级组织方式。

当前不足：

- 没有三平台视频文件下载闭环；
- 小红书和抖音主要是页面内容提取；
- 没有本地ASR；
- Python/Tauri实现不能直接进入Android核心。

定位：部分参考，不作为主代码基座。

### 4.2 `多平台发布工具包.zip`

本地文件：[多平台发布工具包.zip](C:/Users/AIMFl/Downloads/多平台发布工具包.zip)

静态检查结果：

- 主体为 `MatrixMedia / matrix-video 0.10.2`；
- Electron + Vue 2 + Puppeteer；
- GPL-2.0；
- 主要能力是把已有视频自动上传到多个平台；
- 没有分享链接解析、平台视频抓取、字幕提取和ASR。

定位：与当前链接解析和本地文稿主链路无关；后续讨论桌面自动发布时才能作为参考，当前不迁入代码。

## 6. 综合项目与限制

### 6.1 MediaCrawler

项目：[NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)

- 覆盖抖音、小红书、B站等平台的数据和媒体采集；
- 成熟度和社区规模较高；
- 主要定位是爬虫，不是统一视频转写；
- [许可证](https://github.com/NanmiCoder/MediaCrawler/blob/main/LICENSE)限制商业使用。

定位：仅用于理解平台机制，不能迁入商业产品。

### 6.2 btch-downloader

项目：[hostinger-bot/btch-downloader](https://github.com/hostinger-bot/btch-downloader)

- TypeScript、MIT、支持抖音和小红书；
- npm 包只封装作者提供的远程后端接口；
- 不是真正的本地平台解析；
- 不支持B站和本地ASR；
- 作者后端可用性和数据处理不可由我们控制。

定位：不作为本地优先产品核心。

## 7. 迁移规则

引入任何参考项目代码前必须满足：

1. 许可证允许当前商业用途；
2. 只迁移明确需要的最小部分；
3. 改造成当前 `PlatformAdapter` 或运行时契约；
4. 不携带第三方UI、数据库、任务框架和无关依赖；
5. 保存来源、许可证和必要版权声明；
6. 使用公开样本验证当前仍然有效；
7. 不把依赖云端解析的方案描述为本地实现；
8. 未声明许可证的仓库必须先取得授权，或者只研究其行为并独立实现。

## 8. 当前建议顺序

1. 以 UmaoVDownloader 的行为和输出作为抖音/小红书原型参考，但不直接复制无许可证代码；
2. 从许可证明确的项目中选择可迁移实现；
3. 优先完成一个平台的链接解析和视频下载；
4. 再接入统一本地ASR；
5. B站优先使用平台已有字幕，再考虑ASR；
6. 三个平台稳定后才进入Capacitor/Kotlin手机端接入。

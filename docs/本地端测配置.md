# 本地端测配置

> 最后校对：2026-08-14。本文只保存公开地址、模型名、脱敏样例和操作方法，不保存 API Key。

## 小米 MiMo

```text
Base URL: https://api.xiaomimimo.com/v1
文本模型: mimo-v2.5
视觉模型: mimo-v2.5
ASR 模型: mimo-v2.5-asr
ASR transport: chat-input-audio
```

## 阶跃星辰

```text
Base URL: https://api.stepfun.com/v1
文本模型: step-3.5-flash
视觉模型: step-1o-turbo-vision
ASR 模型: stepaudio-2.5-asr
```

实际模型名和权限以供应商账号控制台为准。应用只在 Provider 边界匹配小米与阶跃的推理字段；业务 Flow 仍使用统一的 OpenAI 兼容接口。

## 密钥放在哪里

- 手机 APK：在应用“设置 → AI 连接”中填写，密钥进入 Android Keystore。
- CLI：复制 `.env.example` 为本机 `.env`，只填写 `HONGTAI_AI_API_KEY`；`.env` 已被 Git 忽略。
- 禁止把真实密钥写进源码、文档、命令历史、截图、日志、ADB 参数或 Git。

聊天中已经暴露过的密钥应视为可能泄露。项目完成或端测结束后，必须在供应商控制台撤销并重新生成，不能因为仓库没有保存就继续长期使用。

# 当前能力与发布状态

> 最后校对：2026-08-10。本文是能力和发布成熟度的当前来源；日期验收文档仅保存当时证据。

## 一句话结论

APK 已具备本地档案、AI 设置、公开链接采集、内容拆解、图片观察与本地视频制作的运行时链路；素材库和发布仍未接入。`v0.0.1` 已建立受控非 Debug release 签名与主机验签链，并在 API 35 模拟器完成同 release 证书 v3→v4 普通升级、档案保留与基础冷启动；物理真机和其他发布门禁尚未完成，**仍不可正式分发**。

## 运行时能力矩阵

以下能力来自 `packages/capacitor-runtime/src/standalone-app-runtime.ts` 的 `FeatureCapabilityRegistry`。`available` 表示运行时已接入，不等同于所有设备、所有网络或正式分发均已验收。

| 能力 | 状态 | 用户可做的事 | 重要边界 |
| --- | --- | --- | --- |
| 本地档案 | available | 编辑显示名、门店信息与私有头像 | 无登录、无云同步 |
| AI 设置 | available | 保存 OpenAI 兼容连接并分别探测文本、视觉、ASR | Key 只进入 Android Keystore |
| URL 采集 | available | 处理公开单条作品并显示七阶段真实事件 | 不处理 Cookie、登录、批量采集或绕过风控 |
| 内容拆解 | available | 基于真实转写或图文证据主动运行 `content-analysis.v1` | 不自动开始，不伪造证据 |
| 图片观察 | available | 选择舌象或面部单张图片、生成观察报告并追问 | 仅日常参考，不是医疗诊断 |
| 本地视频制作 | available | 基于成功拆解导入本机素材、生成计划并在设备合成 MP4 | 仍有生命周期、并发和存储治理风险 |
| 素材库 | planned | 显示明确的未接入状态 | 不创建假素材或假搜索结果 |
| 发布 | planned | 显示明确的未接入状态 | 不唤起平台、不伪造发布成功 |

## 最小验证基线

每次变更按影响范围选择验证，详情见[任务执行模板](任务执行模板.md)：

- TypeScript：`pnpm check` 与定向测试；
- Web：`pnpm --filter @hongtai/web build`，视觉改动补桌面与约 390px 截图；
- Android：相关 Gradle 单测、lint、构建；外部媒体、网络和 Media3 改动补真机证据；
- Release：签名、递增版本号、APK SHA-256 和不带降级参数的升级测试。

不要把“构建成功”“模拟器通过”或“某一个 AI 探测成功”表述为正式 release、物理真机或全部模型能力均已验证。
